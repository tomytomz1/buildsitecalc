# Outreach drafts

Companion to `authority-prospects.md`. Everything below is ready to send after
you fill the bracketed fields. Do not batch-send: each template has one or two
spots that must reference the specific page, and those sentences are the only
reason any of this works.

## Rules that keep this non-spammy

- Send from a real named address you monitor, not `hello@`. A reply that lands
  in an unwatched inbox is a lost link.
- Never claim a broken link, a "quick question", or an existing relationship
  that does not exist. Librarians and extension editors read dozens of these a
  month and pattern-match instantly.
- Disclose that the site runs ads. It is free, there is no signup, and no email
  is collected — say all three, because that is what an institutional editor has
  to justify internally.
- One follow-up maximum, and only if the first mail went unanswered for two
  weeks. Then stop, permanently.
- Do not offer a reciprocal link to a .edu page. It reads as a scheme and it is
  one.
- If someone declines, mark it declined and never re-pitch that domain.

## Template E — journalist request pitch

writer can paste it without editing.

## Template F — embeddable widget offer

For trade blogs, local suppliers, landscaping companies and contractor sites
that already publish how-to content. This is the only template where the ask
gives them something first, so it converts best and scales worst.

Subject: `Free embeddable [CALCULATOR] for your [POST TITLE] post`

> Hi [NAME],
>
> Your post [POST TITLE] explains [SPECIFIC THING] well. If you'd like a working
> calculator inside the post rather than sending readers off-site, ours embeds
> as a single iframe:
>
> ```html
> <iframe
>   src="https://buildsitecalc.com/embed/en/[SLUG]"
>   width="100%"
>   height="720"
>   style="border:1px solid #e5e7eb;border-radius:12px"
>   title="[CALCULATOR] calculator"
>   loading="lazy"
> ></iframe>
> ```
>
> No script, no tracking beyond standard server logs, no signup, and it keeps
> working if you never talk to me again. It carries a small link back to the full
> version, which is the whole business model — worth saying plainly rather than
> hiding it in a footer.
>
> Spanish version: swap `/en/` for `/es/` in that URL.
>
> [YOUR NAME]

Copy the exact snippet from the "Put this calculator on your site" section of
any calculator page rather than hand-editing the one above, so the slug and
attribution stay correct.
