# Authority workstream — prospect list and cadence

Built 2026-08-03. Acceptance criterion for this workstream: **5+ referring
domains by day 90**.

Every URL in the tables below was fetched and returned HTTP 200 on 2026-08-03.
Nothing here is a guessed URL. What is _not_ verified, and cannot be from
outside, is whether a given page's owner will add a link — so the list is sized
at roughly 4x the target so a 25% hit rate still clears the acceptance bar.

The honest framing to keep in mind while sending these: the site is under two
months old with no backlink history, so the pitch cannot be "we are an
authority." It has to be "here is a specific tool that answers the exact
question your page already tells readers to go find elsewhere." Three of the
prospects below literally instruct readers to go search for a calculator. Those
are the strongest ones.

Filter rule for the inbox: only pitch queries where the answer is a number the
site computes. Generic "expert tips on home renovation" queries are saturated
with AI-written pitches and are not worth the time. Queries like "how much does
it cost to retile a bathroom" or "how do homeowners underestimate materials" are
answerable with actual output from `/en/calculators/tile` and
`/en/calculators/project-waste-factor`, and that specificity is what still wins
citations.

## Entity signal - the social config

`organizationJsonLd()` emits a `sameAs` array built from
`getConfiguredSocialLinks()`, which reads five environment variables and drops
anything that is not a valid absolute http(s) URL. The code side is therefore
done; the remaining work is creating the profiles, in this order:

| Priority | Network   | Env var                        | Why this order                                                                |
| -------- | --------- | ------------------------------ | ----------------------------------------------------------------------------- |
| 1        | Pinterest | `NEXT_PUBLIC_SOCIAL_PINTEREST` | Home improvement is Pinterest's strongest vertical and pins are indexable     |
| 2        | X         | `NEXT_PUBLIC_SOCIAL_TWITTER`   | Needed anyway to work the #journorequest feed in Tier 4                       |
| 3        | YouTube   | `NEXT_PUBLIC_SOCIAL_YOUTUBE`   | One screen-recorded walkthrough per calculator is cheap and links back        |
| 4        | Facebook  | `NEXT_PUBLIC_SOCIAL_FACEBOOK`  | Local contractor and DIY groups are where the Spanish audience actually is    |
| 5        | LinkedIn  | `NEXT_PUBLIC_SOCIAL_LINKEDIN`  | Lowest value for this audience; only worth it if you pitch trade publications |

Set only the ones that exist. A `sameAs` pointing at an empty or dead profile is
an entity mismatch, which is worse than no `sameAs` at all, and the validator in
`src/config/site.ts` exists to make that mistake impossible.

Verify after deploying: view source on any page and confirm the Organization
JSON-LD block contains a `sameAs` array listing exactly the profiles you
created. The unit test in
`src/lib/calculators/__tests__/paint-stair-units.test.ts` asserts that invariant
in either state, so it will not silently pass once the variables are set.

## Cadence (2 human hours per week)

| When      | Do                                                                                                                | Time   |
| --------- | ----------------------------------------------------------------------------------------------------------------- | ------ |
| Week 1    | Submit the three directories. Sign up for all five request platforms with a filtered inbox rule.                  | 45 min |
| Week 1    | Send prospects 1-5 using the matching template in `outreach-templates.md`.                                        | 45 min |
| Weekly    | Send the next 5 prospects. Never send more than 10 in a week; these are individually written or they do not work. | 45 min |
| Weekly    | Scan the request digests, pitch at most 3, only where the answer is a computed number.                            | 60 min |
| Week 3, 6 | One follow-up per unanswered prospect, maximum one. Then stop.                                                    | 20 min |
| Week 4, 8 | Re-run the referring-domain check below and update the status column here.                                        | 10 min |

## Tracking

Keep the status inline in this file — a spreadsheet is a second place to forget.
Add a column per prospect as you go: `sent YYYY-MM-DD`, `replied`, `linked`,
`declined`, `bounced`.

Check referring domains against the acceptance criterion two ways, because at
this volume the free tools disagree:

1. Search Console, Links report, "Top linking sites". This is the number that
   matters — it is what Google admits it sees.
2. `site:` and plain-text searches for `buildsitecalc.com` to catch links Search
   Console has not picked up yet.

Day 90 read: 5+ distinct referring domains in the GSC Links report means this
workstream worked. 1-2 means the pitch is wrong, not the channel — rewrite the
angle rather than sending more of the same. Zero replies across 40 sends means
stop and reconsider whether the embeddable widget plus directories alone carry
the entity signal.
